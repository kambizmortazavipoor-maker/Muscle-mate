# MUSCLE MATE — نسخه وب آزمایشی

## امکانات موجود
- رابط فارسی/انگلیسی
- ثبت تمرین (حرکت، وزنه، ست، تکرار و تاریخ)
- ثبت تغذیه و کالری/پروتئین/کربوهیدرات/چربی
- ثبت دستی آب و قدم‌ها
- خلاصه امروز و تاریخچه
- ذخیره در مرورگر و پشتیبان‌گیری/بازیابی JSON
- فایل‌های پایه PWA برای نصب از مرورگر پس از میزبانی روی HTTPS

## اجرا
فایل `index.html` را برای تست در مرورگر باز کنید. برای نصب به‌صورت PWA و کار آفلاین قابل اتکا، کل محتویات پوشه را روی یک سرویس HTTPS مانند GitHub Pages میزبانی کنید، سپس در Chrome اندروید از منو گزینه `Install app` یا `Add to Home screen` را بزنید.

## محدودیت‌ها
- این نسخه هنوز با APK اندروید همگام‌سازی نمی‌شود.
- داده‌ها فقط در فضای ذخیره‌سازی همان مرورگر/دستگاه می‌مانند؛ پاک‌کردن داده‌های مرورگر می‌تواند آن‌ها را حذف کند. مرتب فایل پشتیبان JSON بگیرید.
- شمارش قدم خودکار، محاسبه انرژی فعالیت، کتابخانه غذایی معتبر، تحلیل ریکاوری عضلات و پیشنهاد پیشرفت وزنه هنوز پیاده‌سازی نشده‌اند.
- این نسخه یک نمونه وب اولیه است و هنوز تست امنیتی/کاربری گسترده نشده است.
